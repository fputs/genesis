# Producer process
- **Monitoring:** Producer checks CI runs, open PRs, and releases on fputs/genesis twice a day, around 9:00 AM and 5:00 PM PT. Reports go to Chief of Staff only for a red build on main, a PR with no activity for 3+ days, a release, or something that needs Evan. A red pull-request check is the send-back. The router wakes Architect once per head SHA after that head's CI finishes. A red build on main is routed to Architect with links.
- **Changelog:** CHANGELOG.md lives at the repo root and uses Keep a Changelog format, with an Unreleased section. It starts at v2, and v1 history is on the v1-reference branch. The implementation pull request writes that Unreleased entry before the work is done. Spec-only, docs-only, and archive-only pull requests do not. There is no separate changelog pull request after merge. DevOps cuts a release: DevOps adds `## [x.y.z] - YYYY-MM-DD` and moves the bullets then under `## [Unreleased]` into that section. Only DevOps MAY add a version heading; no other role MAY. The `pr-hygiene` job enforces the Unreleased bullet and archive-last.
- **Limits:** Producer does not fix code, review design, merge, re-run jobs, force-push, or delete branches.
- **Review and escalation:** One change is one draft pull request. Evan approves the spec by a review whose body line is `spec-approved: <sha>` on that pull request. He does not review implementation code. Designer rules there before tests or code. Archive once, as the last commit on that pull request, only after Architect and QA have both passed the current head. Never un-archive. If a fix is needed after the archive, Architect escalates to Chief of Staff. Architect merges when CI is green after that archive commit. Architect and QA have both passed the head that was archived. No per-PR Chief of Staff acceptance. Chief of Staff spot-checks merged PRs daily. After two send-back rounds the PR escalates to Chief of Staff. Producer also escalates red CI on main, a PR stalled 3+ days, or a pull request waiting on Evan's `spec-approved` review for 2+ days.
