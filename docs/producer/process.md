# Producer process
- **Monitoring:** Producer checks CI runs, open PRs, and releases on fputs/genesis twice a day, around 9:00 AM and 5:00 PM PT. Reports go to Chief of Staff only for a red build, a PR with no activity for 3+ days, a release, or something that needs Evan. Build and code failures are routed to Architect with links.
- **Changelog:** CHANGELOG.md lives at the repo root and uses Keep a Changelog format, with an Unreleased section. It starts at v2, and v1 history is on the v1-reference branch. The implementation pull request writes that Unreleased entry before the work is done. Spec-only, docs-only, and archive-only pull requests do not. There is no separate changelog pull request after merge.
- **Limits:** Producer does not fix code, review design, merge, re-run jobs, force-push, or delete branches.
- **Review and escalation:** Evan reviews only spec PRs. Architect merges implementation PRs after CI passes, Architect has reviewed, and Chief of Staff has accepted. Producer escalates to Chief of Staff only for red CI on main, a PR stalled 3+ days, or a spec PR waiting on Evan for 2+ days.
