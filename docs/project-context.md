# Project context

- **Product name / repo:** Genesis — [fputs/genesis](https://github.com/fputs/genesis)
- **What we ship:** A Rust game engine + in-product content editor for a faithful Pathfinder 2e classic CRPG (isometric / Infinity Engine–style).
- **What we do not ship here:** Campaign narrative, adventure scripts, or setting lore as product goals. Generated/basic test game data is in-repo only as fixtures to exercise engine and editor.
- **Long-term shape:** Engine and editor are the product; the eventual real game is the “test data” the stack is proven against.
- **Constitution:** [constitution.md](./constitution.md) (principles I–VIII; fixed 4-PC party).
- **First vertical:** [mvp-slice-1.md](./mvp-slice-1.md) — explore small room → fight one enemy; 4× L1 fighters; Move + Strike only.
- **MVP architecture:** [mvp-architecture.md](./mvp-architecture.md).
- **Stack (locked):** Bevy; hand fixtures; Remaster naming; snap-to-grid on encounter. Research: [corpus](./research/README.md), [recommendation](./research/stack-recommendation.md).
- **Canonical remote:** https://github.com/fputs/genesis
