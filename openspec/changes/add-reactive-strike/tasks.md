# Tasks

Each scenario in `specs/reactive-strike/spec.md` has exactly one test. The test name is the scenario title in snake_case. Spaces, hyphens, and apostrophes become `_`. Other punctuation is dropped, then the title is lowercased. `NoReaction` contributes `noreaction`. `TargetDead` contributes `targetdead`. `MAP` contributes `map`. A test comment cites the Player Core section on that requirement. A test that does not roll an attack die builds a `ScriptedDice` and asserts that face is unused. Initiative dice are drawn in ascending `CombatantId` order before the attack die. Do not edit `docs/designer/`. Do not declare `Side`, `Vital`, `Size`, `Square`, `Agility`, `DegreeOfSuccess`, `StrikeOutcome`, or `EncounterError`. Do not call `Encounter::strike` from `reactive_strike`. Do not add a `bool` parameter. Add no dependency. This change names no `v1-reference` file, so none is ported.

Start only after `Vital::Dying` and `Vital::Unconscious` are public. `NotConscious` is `vital != Vital::Alive`.
