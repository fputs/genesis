# Tasks

Each scenario in `specs/reactive-strike/spec.md` and each scenario added under `specs/encounter-turns/spec.md` has exactly one test. The test name is the scenario title in snake_case. Spaces, hyphens, and apostrophes become `_`. Other punctuation is dropped, then the title is lowercased. `NoReaction` contributes `noreaction`. `TargetNotConscious` contributes `targetnotconscious`. `MAP` contributes `map`. A test comment cites the Player Core section on that requirement. A test that does not roll an attack die builds a `ScriptedDice` and asserts that face is unused. Initiative dice are drawn in ascending `CombatantId` order before the attack die. Do not edit `docs/designer/`. Do not declare `Side`, `Vital`, `Size`, `Square`, `Agility`, `DegreeOfSuccess`, `StrikeOutcome`, `ActionCost`, `ActionTrait`, `MoveAction`, or `EncounterError`. Do not declare `Activity`. Do not call `Encounter::strike` from `reactive_strike`. Do not call `note_hit_points`. Do not add a `bool` parameter. Add no dependency. This change names no `v1-reference` file, so none is ported.

Start only after dying-and-victory's `Vital::Dying` and `Vital::Unconscious` are public and `apply_resolved_blow` is in the crate, and after positioning's `ActionCost` and `ActionTrait` are in the crate. `NotConscious` and `TargetNotConscious` are `vital != Vital::Alive`. Extend that one `ActionTrait` with `Manipulate` and `Ranged`. Do not add a second enum.

The error order is the same here, in design.md, and in the spec: `UnknownCombatant` for the reactor, then the actor, `NotConscious`, `SelfTarget`, `Unavailable`, `NotATrigger`, `UnsupportedSize`, `Overflow`, `InvalidReach`, `OutOfReach`, `TargetNotConscious`, then `NoReaction`.
