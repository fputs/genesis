# Tasks

Each scenario under this change has one test. The test name is the scenario title in snake_case. Spaces and hyphens become `_`. Other punctuation is dropped, then the title is lowercased. A plus sign before a number is written `plus_` and that number, so `+2` becomes `plus_2` and `Plus1` becomes `plus_1`. A minus sign before a number is written `minus_` and that number, so `-1` becomes `minus_1` and `Minus1` becomes `minus_1`. `NotConscious` contributes `notconscious`. `NoReaction` contributes `noreaction`. `NotAnAlly` contributes `notanally`. `NotThePreparedAlly` contributes `notthepreparedally`. `SelfTarget` contributes `selftarget`. `NotYourTurn` contributes `notyourturn`. `TurnNotOpen` contributes `turnnotopen`. `AidOverflow` contributes `aidoverflow`. The existing creature-template titles keep `success_grants_plus_1`, `critical_success_grants_plus_2`, and `critical_failure_grants_minus_1`. Tests use `ScriptedDice` and assert a held face is unused unless the scenario says it was drawn. Cite the Player Core section on that scenario's requirement. Assert through the public functions in design.md. Do not edit `docs/designer/`. Do not add a dependency. No bool parameter. `AidPreparation` is `NotPrepared` or `Prepared { ally }`. This change names no file on `v1-reference`, so none is ported.

Start only after `Vital::Unconscious` and `Vital::Dying` are public. Do not add a second degree function. Do not teach `Encounter::strike` to store an Aid bonus. Do not call `CheckModifier::new` for the Aid roll.
