# Tasks

Each scenario under this change has one test. The test name is the scenario title in snake_case. Spaces and hyphens become `_`. Other punctuation is dropped, then the title is lowercased. `NotConscious` contributes `notconscious`. `NoReaction` contributes `noreaction`. `NotAnAlly` contributes `notanally`. `SelfTarget` contributes `selftarget`. `NotYourTurn` contributes `notyourturn`. The existing creature-template titles keep `success_grants_plus_1`, `critical_success_grants_plus_2`, and `critical_failure_grants_minus_1`. Tests use `ScriptedDice` and assert a held face is unused unless the scenario says it was drawn. Cite the Player Core section on that scenario's requirement. Assert through the public functions in design.md. Do not edit `docs/designer/`. Do not add a dependency. No bool parameter. `AidPreparation` is `NotPrepared` or `Prepared`. This change names no file on `v1-reference`, so none is ported.

Start only after `Vital::Unconscious` and `Vital::Dying` are public. Do not add a second degree function. Do not teach `Encounter::strike` to store an Aid bonus.
