# Tasks

Each scenario under this change has one test. The test name is the scenario title in snake_case. Spaces, hyphens, and apostrophes become `_`. Other punctuation is dropped, then the title is lowercased. `Off-guard` contributes `off_guard`. `NotAHit` contributes `notahit`. `Dying(1)` contributes `dying1`. Tests use `ScriptedDice` when they hold a die, and they assert that die is unused unless the scenario says it was drawn. Cite the Player Core section on that scenario's requirement. Assert through the public functions in design.md. Do not edit `docs/designer/`. Do not declare `Side`, `OffGuard`, `DegreeOfSuccess`, or `HpError::NotAHit`. Do not add a dependency. This change names no file on `v1-reference`, so none is ported.

Start only after `apply_resolved_blow`, `Vital::Dying`, and `Encounter::start_turn` exist on main. Do not add a second creature-damage formula. `ShieldBlock` is `Requested` or `Declined`. No `bool` parameter.
