Use the resolved path for amount 0 and for 2147483647. Do not add a helper per test. Dice scenarios keep `apply_dice_damage`. `reflex_modifiers` keeps `unconscious: bool`, matching `perception_modifiers` and `ac_modifiers`, as design.md says.
