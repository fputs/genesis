# Tasks

Each scenario under this change has one test. The test name is the scenario title in snake_case. Spaces become `_`. A hyphen between words becomes `_`. A hyphen before a number becomes `minus`. Other punctuation is dropped, then the title is lowercased. `TurnNotOpen` contributes `turnnotopen`. `NotYourTurn` contributes `notyourturn`. `NotConscious` contributes `notconscious`. Tests use `ScriptedDice` and assert a held face is unused unless the scenario says it was drawn. Cite the Player Core section on that scenario's requirement. Assert through the public functions in design.md, including `stored_ready`, `frozen_attack_count`, `turn_slot`, `next_start`, `initiative_total`, and `round`. Do not edit `docs/designer/`. Do not add a dependency. Do not add a crate. No bool parameter and no `delayed` bool. `TurnSlot` is `Normal`, `Delayed`, `Returned`, or `SkipStartHook`. `MapInput.readied_attack_count` is on main (`0185586`). Pass `Some(snapshot)` from a readied attack and `None` from `attack_trait_penalty`. Do not add a second penalty table. Do not call `dying::start_of_turn`. This change names no file on `v1-reference`, so none is ported.
